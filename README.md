Learn Smarter with AI – Your personal AI-powered tutor for instant explanations,
concept clarification, and interactive learning. 🚀📚


AI Tutor is an intelligent web-based learning assistant powered by Generative AI that provides personalized academic support to students. Built using Flask and the Groq API, the platform enables users to ask questions on various subjects and receive instant, clear, and context-aware explanations.

The application acts as a virtual tutor, helping learners understand concepts, solve problems, and improve their knowledge through interactive conversations. With a simple and user-friendly interface, AI Tutor makes learning more accessible, engaging, and efficient.

Key Features
🤖 AI-powered question answering
📚 Personalized learning assistance
⚡ Fast responses using Groq LLMs
💬 Interactive chat-based interface
🎓 Supports multiple academic subjects
🌐 Lightweight and responsive web application
🔒 Secure API key management using environment variables
Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Flask (Python)
AI Model: Groq API (LLM)
Environment Management: python-dotenv
Deployment: Render/Gunicorn
